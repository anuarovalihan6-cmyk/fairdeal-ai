# FairDeal AI — с чего начать

Приложение работает на вашем компьютере. Интерфейс на английском, примеры используют вымышленных людей. Ничего не опубликовано в интернете.

## 1. Откройте приложение

1. Откройте папку `fairdeal-ai`.
2. Дважды нажмите `START.cmd`.
3. Дождитесь строки `Ready` и откройте **http://localhost:3000**.
4. Не закрывайте окно запуска, пока пользуетесь приложением. Чтобы остановить его, нажмите в этом окне `Ctrl+C`.

Node.js 24 уже обнаружен на вашем компьютере. Библиотеки уже установлены. При переносе на другой компьютер `START.cmd` сам скачает бесплатные библиотеки, если установлен Node.js 24.

Если порт 3000 занят другим приложением, остановите предыдущий экземпляр FairDeal AI. Для платежного возврата адрес приложения и `APP_URL` должны совпадать. Для хакатона используйте порт 3000.

## 2. Попробуйте демо без ключей

Вверху справа появились кнопки **EN / RU**. Нажмите **RU** для русского интерфейса; выбор сохраняется после перезагрузки. Новый пример кофейни и его анализ будут на выбранном языке. Стандартные тексты демопроекта, этапов и анализа отображаются на выбранном языке, даже если проект создан раньше. Сохранённый оригинал и экспорт не меняются. Свой произвольный текст приложение не переводит автоматически: для демопримеров используются готовые переводы без обращения к платным сервисам.

1. Нажмите **New deal → Try the coffee shop example → Create agreement**.
2. В разделе **Agreement** посмотрите и при необходимости измените соглашение через **Edit agreement**.
3. Откройте **Risk scanner → Run risk scan**. Пример намеренно содержит три неясных условия.
4. Нажмите **Review suggested wording**, изучите предложенную правку и сохраните соглашение. Повторный скан покажет оставшиеся замечания.
5. В **Milestones** откройте **Submit work & review**, добавьте описание результата и нажмите **Save submission**. Затем можно отметить **Record work acceptance**.
6. В **Deal mediator** оставьте пример разногласия и нажмите **Find common ground**. Результат ссылается на реальные пункты сохранённого соглашения.

На русском те же шаги называются **Новый проект → Взять пример кофейни → Создать соглашение**, **Проверка рисков**, **Этапы**, **Результат и приёмка**, **Разбор спора → Найти общее решение**.

В этом режиме соглашение — адаптированный образец, сканер — локальные проверки, а разбор спора — шаблон, связанный с соглашением. Подписи прямо указывают это. Это не ответы работающей нейросети.

## 3. Подключите PayPal Sandbox

Секреты вводите только на своём компьютере. Не отправляйте их в чат.

1. На [PayPal Developer](https://developer.paypal.com/dashboard/applications/sandbox) выберите **Sandbox**, затем ваше REST-приложение для тестового Business-аккаунта.
2. В папке приложения дважды нажмите **SETUP.cmd**. Откроется окно приватной настройки.
3. Скопируйте **Client ID** в первый запрос. Символы будут скрыты — это нормально. Нажмите Enter.
4. Скопируйте **Client Secret** во второй запрос. Это секрет приложения, а не ваш пароль PayPal.
5. Если ключа Gemini пока нет, пропустите следующий запрос клавишей Enter.
6. Остановите приложение через `Ctrl+C` и снова запустите **START.cmd**.
7. В **Payments** выберите первый этап за $90 и нажмите **Pay**.
8. На сайте **sandbox.paypal.com** войдите под тестовым **Personal**-аккаунтом. Он должен отличаться от Business-аккаунта получателя. Подтвердите тестовую оплату.
9. После возврата в FairDeal AI нажмите **Confirm Sandbox payment**.
10. Успех подтверждён только тогда, когда в истории появились **Sandbox verified**, Order ID и Capture ID. Сверьте эти номера с активностью тестового Business-аккаунта.

Если ответ потерялся, нажмите **Verify**. Приложение проверит прежний заказ. Не создавайте оплату вручную в другом месте.

Отмена checkout не означает аннулирование заказа на стороне PayPal. Приложение сохраняет его номер и при продолжении использует тот же заказ. Соглашение после создания заказа блокируется для сохранения соответствия суммам; новые условия оформляйте новым проектом.

## 4. При желании подключите бесплатный Gemini

1. Откройте [Google AI Studio](https://aistudio.google.com/api-keys).
2. Используйте проект **Free Tier без привязанного платёжного аккаунта**. Не подключайте оплату и банковскую карту.
3. Введите ключ через **SETUP.cmd**. Имеющиеся ключи PayPal можно оставить, нажимая Enter.
4. Проверьте бесплатный статус проекта и только после этого напишите `FREE` в последнем запросе настройки.
5. Перезапустите приложение. В списке **Demo examples** станет доступен **Live AI**.

Приложение не может само проверить тариф Google по ключу. Если вы не уверены, оставьте Gemini выключенным. Демо полностью работает без него. При ошибке, лимите или неверном ответе показывается подписанный локальный пример. Автоматической покупки или перехода на платный тариф нет.

## Где находятся данные

- `.env.local` — приватные ключи. Файл исключён из Git.
- `data/fairdeal.sqlite` — проекты, работы и платежные ссылки на этом компьютере.
- `README.md` — технические инструкции и ограничения.
- `docs/DEMO-SCRIPT.md` — трёхминутный сценарий на английском.
- `docs/DEVPOST.md` — заготовка описания проекта.
- `docs/TESTING.md` — что и как проверено.

Не публикуйте `.env.local`, папку `data`, `node_modules` или архив всей рабочей папки без проверки. Для передачи исходников подготовлен отдельный архив без ключей и базы.
