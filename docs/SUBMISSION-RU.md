# Как подать FairDeal AI

Страница хакатона: [PayPal AI Hackathon на Devpost](https://paypalaihackathon.devpost.com/).

1. Войдите в свой Devpost. Если ещё не участвуете, нажмите **Join hackathon** и самостоятельно проверьте условия участия.
2. Откройте **My projects**, затем создание заявки или **Enter a submission**. Если заявка уже есть, продолжайте её редактирование, чтобы не создавать дубликат.
3. Добавьте название FairDeal AI, английское описание из [DEVPOST.md](DEVPOST.md), использованные технологии и ссылку на публичный репозиторий GitHub.
4. Запишите работающий проект по [сценарию на 2:45](DEMO-SCRIPT.md). Голос в правилах прямо не требуется. Можно говорить по-русски и добавить английские субтитры. Интерфейс на записи удобнее переключить на EN.
5. Загрузите ролик на YouTube с доступом **Public / Открытый** и вставьте ссылку в заявку.
6. Укажите, что приложение запускается локально по README. Публичный хостинг не обязателен. Для собственных живых тестов PayPal и Gemini нужны ключи проверяющего; без них доступен явно подписанный демо-режим. Не размещайте свои ключи или пароли в репозитории, ролике либо публичном описании.
7. Проверьте все поля, доступность ролика и репозитория, соответствие правилам и завершите подачу на Devpost. Публикация кода на GitHub сама по себе не отправляет заявку.

По [официальным правилам](https://paypalaihackathon.devpost.com/rules) нужны осмысленная интеграция PayPal Sandbox и ИИ, рабочий проект, описание, публичный репозиторий с открытой лицензией, видео короче трёх минут и английские материалы либо английский перевод. Дедлайн, показанный Devpost для GMT+5: **13 ноября 2026 года, 01:00**. Перед отправкой проверьте дату на странице хакатона.

Исходники включают лицензию MIT и инструкции запуска. В личной локальной базе уже проверены два Sandbox-списания ($90 и $120) и живые запросы Gemini. База и ключи в публикацию не входят. Итоговая ссылка на видео добавляется только после записи; этот файл не означает, что заявка уже отправлена.
