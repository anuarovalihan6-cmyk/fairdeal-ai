# FairDeal AI — 2:45 demonstration

Target length: **2 minutes 45 seconds**, leaving room below the official three-minute limit. Narration is not expressly required by the [official rules](https://paypalaihackathon.devpost.com/rules). All submitted materials must be in English or include an English translation. English narration and captions, or Russian narration with English subtitles, can explain the same workflow. Upload the final video publicly to YouTube and put its URL in Devpost.

Before recording: select EN, prepare a fictional coffee-shop project, choose Live AI with a verified Free Tier Gemini project, and rehearse each action. Keep provider keys, account settings, real identities, and password managers off-screen. Only call output live when its source badge says **Live AI**. Provider loading time may be trimmed with a visible cut; never substitute a local sample for a successful live response.

The verified $300 website project and the $240 printed-menu QA project are separate examples. If switching between projects, identify the switch. Do not imply that a completed payment belongs to another agreement.

Show the overview and Sandbox-only indicator.

“A freelance project can start with one brief and end with two different expectations. FairDeal AI helps a client and freelancer agree on scope, track the work, and resolve misunderstandings using the same written terms.”

“Our fictional coffee shop needs a three-page website for three hundred dollars. Gemini turns the brief into structured terms and milestones. The server validates dates and exact budget totals. Both parties can review the draft.”

Show both statements about online checkout and a successful live mediation report. Use the source badge and exact saved clause references. Rehearse the request before recording; keep failure labels visible if it fails.
